# simple-todo-application-33177-33197

This workspace contains the todo_frontend React app implementing a simple in-memory Retro Todo with the Ocean Professional theme.

- Add tasks with the input and Add button or by pressing Enter.
- View tasks in a modern, clean list.
- Delete tasks with the delete button.
- No backend calls; state is client-side only.

To run the frontend:
1. cd todo_frontend
2. npm install
3. npm start

The app will be available at http://localhost:3000.
